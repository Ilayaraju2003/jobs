Job Description

As a Cloud Support Agent, you will be the first point of contact for users experiencing technical issues within Google Cloud Platform (GCP) and Google Workspace.

You will troubleshoot cloud infrastructure, assist users, monitor systems, analyze logs, and ensure secure cloud operations while maintaining excellent customer satisfaction.

Key Responsibilities

  • Monitor tickets using Jira and ServiceNow.
  • Support Compute Engine and Cloud Storage services.
  • Troubleshoot Cloud SQL connectivity issues.
  • Manage Google Workspace accounts.
  • Password reset and 2-Step Verification recovery.
  • Monitor Google Cloud Operations Suite.
  • Analyze Cloud Logs and alerts.
  • Follow standard runbooks and SOPs.
  • Provide high-quality customer support.

Eligibility Criteria

  • Bachelor's Degree in Computer Science / IT.
  • 0-2 years experience in IT Support or Cloud Operations.
  • Strong communication skills.
  • Customer-first mindset.

Required Skills

GCP Compute Engine Cloud Storage IAM VPC Networking Google Workspace Cloud Logging Cloud Monitoring Jira ServiceNow Gemini AI

Preferred Certifications

  • Google Cloud Digital Leader (Required)
  • Associate Cloud Engineer (Preferred)
